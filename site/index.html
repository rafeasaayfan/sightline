      07

      Accessible on purpose

      Measured, not assumed. The full audit, item by item, is in the repository.

      • 100Lighthouse accessibility
      • 5.28 : 1lowest text contrast, over a pure white frame
      • 48 pxtouch targets on phones
      • 0layout shift while the page loads
      • Keyboard first. Every control in visual order, one visible ring, menus close with Esc and hand focus back.
      • Never colour alone. Markers differ by shape; "on" states change shape or label too.
      • Calm on request. Reduced motion stops the sweep, the pulse and the spinner; swaps cut instead of fade.
      • Forced colours. System colours throughout; markers keep their shapes; focus uses Highlight.

      08

      Install

      Vantage is skin source for Video.js 10: copy it into your project and keep the public properties.

      1. Add Video.js 10 and the fonts

        npm i @videojs/html @fontsource/inter @fontsource/space-grotesk @fontsource/jetbrains-mono

      2. Copy the skin and import it

        import '@videojs/html/video/player';
import '@videojs/html/media/mux-video';
import './vantage/video/skin';   // src/ from the repository

      3. Add your stream and its events

        <video-player>
  <!-- skin.html markup, with your media where it says -->
  <mux-video src="https://stream.mux.com/PLAYBACK_ID.m3u8" crossorigin>
    <track kind="metadata" label="events" src="events.vtt" default>
  </mux-video>
</video-player>
